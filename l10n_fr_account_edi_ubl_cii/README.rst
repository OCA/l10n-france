This module extends account_edi_ubl_cii for France. In particular, it
adds a new format UBL 2.1 specific for France and extends Factur-x
format for France.

This module also adds a few functions on account.move, res.company and
res.partner models useful for France e-invoicing.

Most of this module comes from Odoo SA module l10n_fr_pdp from Odoo CE
edition version 18.0

Use Cases / Context
===================

This module has been created in order to implement the changes needed in
UBL/CII/Factur-x formats for France, in particular in the context of
e-invoicing starting in September 2026.

Odoo has implemented a full module for this purpose : l10n_fr_pdp

The problem of that module is that it is written in order to interact
with Odoo as IAP server interfacing with France authorities.

Many Odoo users will not use Odoo IAP server and therefore need XML
invoices without the full l10n_fr_pdp module which also forces the
installation of other modules like account_peppol(\_\*) or TOTP.

We proposed to Odoo to split the module in 2 but they replied that
although it was not planned (see
https://github.com/odoo/odoo/pull/268822), it should not be done this
way but rather adding the necessary changes directly in
account_edi_ubl_cii

Since we do not know when this may happen, we start this module to
implement required changes on XML generation / import for France.

This modules depends only on Odoo core (Community Edition) modules :

-  l10n_fr_account (which depends on l10n_fr and account, base_iban and
   base_vat)
-  account_edi_ubl_cii_tax_extension (which depends on
   acconut_edi_ubl_cii)

Usage
=====

This module almost does not impact the user interface. It only adds a
new choice on partner for XML format (invoice_edi_format) : UBL 2.1
