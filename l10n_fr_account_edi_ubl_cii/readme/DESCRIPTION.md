This module extends account_edi_ubl_cii for France.
In particular, it adds a new format UBL 2.1 specific for France and extends Factur-x format for France.

This module also adds a few functions on account.move, res.company and res.partner models useful for France e-invoicing.

Most of this module comes from Odoo SA module l10n_fr_pdp from Odoo CE edition version 18.0
